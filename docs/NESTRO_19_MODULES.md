## 第十一项：专家模板

目标：提供可复用的专家角色模板，帮助用户快速创建专家，同时不覆盖或破坏现有专家配置。

### 功能范围
- [x] 内置专家模板目录，覆盖研究分析、商业经营、产品研发、内容创作、教育成长、项目管理和风险控制等场景。
- [x] 自定义模板保存：从当前专家配置生成模板；同名自定义模板更新，内置模板名称受保护。
- [x] 模板分类与搜索：支持按分类筛选，并搜索名称、说明和角色指令。
- [x] 使用模板：将模板配置载入专家编辑器，由用户确认后创建或更新专家。
- [x] 自定义模板删除；内置模板不可删除。
- [x] 模板 JSON 导入/导出，导入前预览；同名自定义模板更新，内置模板不可覆盖。
- [x] 模板数量、名称、指令长度、分类、描述和模型参数校验。
- [x] 自定义模板沿用本地持久化与现有备份/恢复链路。
- [ ] JVM 单元测试与 Android UI 回归测试通过。
- [ ] 构建/CI 验证通过后，才将第十一项标记为完成。

### 执行约束
- 模板只保存专家角色配置和提示词，不执行模板内代码。
- 模板应用不会自动授予技能、文件、无障碍或其他系统权限。
- 内置模板与用户自定义模板分开管理；用户数据不得被内置模板更新覆盖。
- 不改变第1项专家系统已有能力，不把第11项拆成新模块。


## 第十二项：双模型对比

目标：让用户用同一条任务指令同时调用两个已配置模型，直观比较回答质量；不修改当前聊天的活动模型，也不把一个模型失败后的请求偷偷切换到另一个模型。

### 功能范围
- [x] 从统一模型目录选择两个不同且当前可用的模型，校验服务商、模型启用状态和可用 API Key。
- [x] 支持不同服务商模型组合；密钥仅在请求时从加密仓库读取，不进入页面状态或比较记录。
- [x] 同一用户提示词和可选系统指令分别发送给两模型，两个请求并行执行，分别流式显示结果。
- [x] 两个请求独立处理失败；一侧失败时保留另一侧已生成内容，不将模型 A 的请求故障切换到模型 B。
- [x] 支持停止本次双模型请求、清空结果、复制任意一侧回答。
- [x] 宽屏并排展示，手机窄屏纵向展示；模型列表随可用模型目录更新。
- [x] 增加模型选择、重复选择、不可用模型、空提示词及长度上限等策略测试。
- [x] 静态源码、分支差异与结构复核完成；括号结构检查通过（不等同于 Kotlin 编译）。
- [ ] Kotlin 编译与 JVM 测试执行；模拟器/真机验收留待十九模块全部开发完成后统一执行。

### 执行约束
- 双模型比较只使用用户明确选择的两个模型；不得静默改用活动模型或其他备用模型。
- 两侧共享同一份用户输入和系统指令，但请求 ID、流式状态、错误和输出相互隔离。
- 停止操作必须取消两侧请求并释放网络连接；任何一侧失败都不能抹掉另一侧结果。
- 比较请求不写入普通聊天记录，不改变当前会话、活动模型或模型故障切换设置。



## 第十三项：MCP 工具中心

目标：把用户自行选择的远程 MCP 服务接入 Nestro 统一工具目录，在不扩大默认权限的前提下完成服务连接、工具发现、逐工具授权、参数预览、执行、审计和撤销。

### 功能范围

- [x] 远程 MCP Streamable HTTP 连接；当前协议优先使用 2026-07-28 stateless 请求格式，并兼容 2025-11-25、2025-06-18、2025-03-26 的 initialize/session 流程。
- [x] JSON-RPC initialize/initialized（旧版兼容）、tools/list 分页、tools/call；解析 JSON 与 SSE 响应及服务端错误。
- [x] HTTPS 地址校验，拒绝 URL 内嵌凭据、query、fragment；关闭 HTTP 自动重定向；请求超时、响应体大小和工具数量均有界。
- [x] Bearer Token 使用独立 Android Keystore AES-GCM 密钥加密保存，支持更新与撤销；凭据不进入工具目录、调用参数或审计记录。
- [x] 工具 schema 缓存与基础参数校验：必填字段、基础类型、额外字段限制、枚举和字符串长度；最终参数仍由 MCP 服务端再次校验。
- [x] 每个 MCP 工具单独授权/撤销；服务停用或删除时同步从统一 AgentToolCatalog 移除对应工具。
- [x] 每次手动调用先展示服务、工具、schema 和实际 JSON 参数预览，再由用户确认执行。
- [x] AgentRuntime 接入统一权限路由；外部 MCP 工具在 Agent 调用路径中始终要求用户确认，不因服务端 readOnlyHint 声明而自动放行。
- [x] 调用结果标记为不可信外部数据；调用审计仅记录服务/工具/时间/成功状态，不记录参数、凭据或完整返回正文；本地保留最近 100 条。
- [x] 取消请求传播至 OkHttp Call；连接超时、读取超时、总超时和响应大小限制；旧版 MCP session 在操作结束时尝试 DELETE 清理。
- [x] 损坏的 MCP 服务配置/工具目录/调用审计先隔离备份；审计原始损坏内容先持久化备份，备份失败则中止恢复流程，不静默丢弃；有效审计写入采用同步读改写，避免并发调用覆盖彼此记录。
- [x] 回归测试源代码：HTTPS 与 URL 凭据边界、工具权限默认策略、JSON 参数校验、Header 值编码、配置编解码与授权状态持久化，以及审计编解码/损坏数据隔离备份/已有备份保护/隔离写入失败传播/数量上限。
- [ ] Kotlin 编译与 JVM 测试执行；模拟器/真机验收留待十九模块全部开发完成后统一执行。

### 执行约束与明确边界

- 仅接入用户明确添加的 HTTPS 远程 Streamable HTTP 服务；不在 Android 设备上启动任意本地 MCP Server，也不实现 stdio 子进程传输。
- MCP 工具发现不等于授权；未授权工具不会注册进 AgentToolCatalog。
- 服务端提供的工具名称、描述、schema、annotations 和返回内容均视为不可信数据。
- readOnlyHint 仅作为界面提示；所有 MCP 工具在 AgentRuntime 路径中均要求用户确认。手动调用必须经过逐次参数预览和确认。
- 工具目录按任务现有 AgentToolSession/AgentCapabilityRegistry 最小权限机制加载；普通聊天不自动加载 MCP 工具定义。
- 当前版本提供 MCP 工具中心和受控手动调用；模型原生 tool-call schema 适配不在本模块内擅自宣称完成。
- 当前模块代码阶段已完成并重新锁定：审计可靠性修复通过 PR #12 合并，commit `97ed25e`。编译、JVM 测试、模拟器与真机验收留待十九模块统一阶段。
- 当前认证方式支持可选 Bearer Token 的加密保存与轮换；OAuth 2.1 交互式授权流程、stdio 子进程传输及服务端主动推送订阅不在本次实现范围。
