## NESTRO 统一智能能力验收基准（2026-11-22 用户确认）

NESTRO 必须实现“听得懂、看得懂、能创作、能执行、会协作”，以文本主模型为统一调度入口：
- 听得懂：实时语音输入、音频文件识别/转写/理解；语音识别与音频文件理解分别验收。
- 看得懂：图片理解、视频内容理解/场景分析；视频理解和视频生成是不同能力。
- 能创作：文本/图像/视频等专业模型能力，专家团手动组队和主模型自主组队均可使用。
- 能执行：Phone Agent 在隔离手机环境执行网页/App操作、素材下载和文件导入。
- 会协作：主模型按依赖动态组合专家创作、手机执行、知识检索和媒体模型；允许多轮穿插、串并行和失败恢复，不强制固定先后顺序。

所有能力优先复用现有 AgentRuntime/AgentToolCatalog、AgentTaskCoordinator、MediaAiTaskStore/Worker、项目素材库和 Provider 配置。仅在确认入口或能力缺失后补最小接口，禁止复制已有 Provider、Worker、任务队列或工具目录。

本文件固定产品模块编号与顺序。不得拆分、合并、增删或重新编号；开发按原编号推进。模块完成口径为功能闭环、数据持久化、异常处理与对应测试通过。最终整机安装、升级、权限、后台、性能与功耗验收仍按产品发布阶段统一执行。
