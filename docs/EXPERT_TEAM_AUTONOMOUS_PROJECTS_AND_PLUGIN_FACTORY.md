# Nestro：统一专家协作、AI 插件工厂与系统助手

状态：核心调度代码已开始接入；完整产品功能与验收尚未完成。本文记录真实代码边界，不把设计目标当作已完成能力。

## 一、统一专家协作系统

这不是两个互斥的专家团模式，而是一套统一的团队、项目、消息、工具权限、任务调度和交付系统，有两个进入入口。

### 主聊天入口：模型自动组队
- 用户直接向常驻主模型描述目标或上传资料，不必先研究专家、Skill 或工作流。
- 主模型先判断普通聊天、单项工具任务或项目型任务；普通问题直接回答，项目型任务再查询当前项目可用专家目录。
- 主模型选择专家、拆分工作包、指定每个工作包的成员、依赖关系和验收标准，形成 DAG。
- 无依赖工作包并发执行；有依赖工作包等前序成果完成后再执行。
- 专家成果返回主模型，由主模型检查完整性、依据、冲突和最终验收标准，再整合成品交付用户。

### 专家中心入口：用户主动组队
- 用户可进入专家中心临时勾选 2–4 位专家，返回聊天后说明任务；也可以使用已保存的固定团队。
- 两个入口共用同一个项目计划、DAG 执行器、工具权限、事件日志和主模型交付流程。
- 默认情况下，主模型和各专家成员复用用户当前选定的同一套模型配置。专家差异来自角色指令、专属 Skill、独立任务上下文和工具能力，不依赖额外小模型。

### 团队交流与用户可见过程
- 每个专家有独立工作包和上下文；依赖工作包会把前序成果交接给后续专家。
- 成员开始、重试、完成、成果提交、依赖交接和团队结束都会生成项目级事件。
- 用户可在专家团队页面查看最近协作时间线。
- 完整的双向自由消息、单个专家私聊、可编辑任务图、暂停/恢复/返工控制、独立项目工作区和完整历史分页仍未完成。
- 临时团队自动创建和执行已接入；自动团队保存为长期团队、手动解散和保留操作仍待补齐。

## 二、当前专家协作代码状态

- `ModelLedToolDispatcher` 将项目型任务的专家组队规划交给主模型，不要求用户预先选队。
- `NestroApp` 将当前项目可见的专家、角色指令和 Skill 摘要注入主模型上下文；模型可提交成员名单与工作包 DAG。
- 专家中心新增临时多选入口；显式选中的专家优先于模型自动选择。
- `ExpertProjectPlanExecutor` 校验成员、工作包、依赖和循环关系，并按拓扑波次执行。
- `ExpertTeamExecutionCoordinator.executeProjectPlan` 将 DAG 任务纳入 `AgentTaskCoordinator` 生命周期，并复用 `AgentCapabilityRegistry` 的任务级工具租约。
- `ExpertTeamCollaborationEvent` / codec 定义有界事件模型；聊天入口将最近 300 条事件保存到本地 SharedPreferences，专家团队页显示最近 16 条。
- 主模型收到专家成果后会被明确要求进行质量检查；工具执行成功不等于最终成品验收通过。但目前还没有独立结构化的验收/返工协议。
- 内部并行工作包和专家交接是调度策略，不是产品层面的双模式。

## 三、AI 自主创造插件

目标是让模型发现能力缺口后，能基于现有能力目录生成新插件，而不是只生成一个专家 Prompt 或 Skill。

本轮新增 `GeneratedPluginFactory`：
- 根据当前已注册 `AgentToolCatalog` 生成声明式插件包，包含插件 ID、SemVer、输入字段、步骤、工具 ID 和参数模板。
- 验证工具是否真实注册、输入是否声明、模板是否只引用输入或前序步骤结果；拒绝递归插件调用及设备控制、身份验证、金融等高风险工具。
- `GeneratedPluginCenterPage` 支持 AI 生成草案、预览输入与步骤、安装（默认关闭）、启用/停用、生成升级草案、版本替换、回滚上一版本和卸载。
- `GeneratedPluginStore` 在本地持久化安装包与有限版本历史；启用的插件才注册到共享能力目录，停用/卸载后从目录移除。
- 执行器按步骤运行，并通过统一 AgentRuntime 回调调用已有工具；不生成任意 Kotlin/Java/Python/JavaScript/Shell 代码，不允许绕过工具自身权限路由。
- 新增插件包 codec 和 JVM 测试源码。

仍未完成：插件签名与来源验证、依赖锁定、独立资源沙箱、完整的插件级审批/审计视图、远程插件目录及导入/导出。因此当前是本地受限声明式插件工坊，不是开放式插件市场或任意代码运行环境。
## 四、Android 系统默认助手

- Manifest 已声明 `ACTION_ASSIST`，系统助手入口可将 MainActivity 导向 Nestro 主聊天页。
- 设置页已加入 `ROLE_ASSISTANT` 可用性检查和系统确认式申请入口。
- Android 是否开放助手角色由系统运行时检查；不能假设每个 Android 版本或 OEM 都支持。
- 尚未实现 `VoiceInteractionService` / `VoiceInteractionSessionService`、常驻热词、锁屏语音会话、屏幕上下文理解和厂商专项适配。当前是系统助手调用入口，不等于完整替换 OEM 助手全部能力。
