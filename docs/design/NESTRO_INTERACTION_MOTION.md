# NERTRO 交互动效规范

版本：Draft 1（与聊天优先极简 UI 同步）

## 目标

动效只负责解释状态变化、保持空间连续和确认用户操作。界面继续保持纯白/纯黑、低装饰、低干扰；不使用霓虹、弹跳、循环光效或大面积位移。动效不能延迟输入、发送、停止、审批等真实操作。

## 全局节奏

| 类型 | 时长 | 用途 |
|---|---:|---|
| 快速反馈 | 100–120 ms | 发送/停止图标切换、轻量状态变化 |
| 标准过渡 | 140–180 ms | 页面淡入淡出、抽屉、消息进入/移除 |
| 内容布局 | spring，低刚度 | 消息插入后的列表位置调整、内容高度变化 |

- 页面切换使用短 Crossfade，不做整屏滑动。
- 手机侧栏从左侧进入/退出；宽屏侧栏只展开/收起宽度。
- 消息新增/删除使用 Lazy 列表 item 动画；列表自动滚动继续沿用现有 animateScrollToItem，不重复造滚动控制器。
- 输入区高度变化使用 animateContentSize；IME 避让仍由 imePadding 负责，两者不能互相替代。
- 动画必须可中断：目标状态变化时跟随最新状态，不启动独立延迟任务或后台动画队列。

## 交互状态矩阵

| 区域 | 状态变化 | 反馈方式 | 当前代码状态 |
|---|---|---|---|
| 语音按钮 | 空闲→录音→识别→空闲 | 已有缩放、颜色、触觉反馈；取消回到空闲 | 已有 |
| 页面主体 | 页面 A→页面 B | 短 Crossfade | 本轮补齐 |
| 手机侧栏 | 关闭↔展开 | 左侧滑入/滑出并淡入淡出 | 本轮补齐 |
| 宽屏侧栏 | 关闭↔展开 | 宽度展开/收起并淡入淡出 | 本轮补齐 |
| 消息列表 | 消息插入/移除/位置变化 | item 淡入淡出与 spring 位移 | 本轮补齐 |
| 任务提示 | 空闲↔思考中 | 轻量展开/收起与淡入淡出 | 本轮补齐 |
| 输入区 | 内容高度变化 | animateContentSize | 本轮补齐 |
| 发送/停止 | 可发送↔执行中 | 图标 Crossfade；业务状态立即切换 | 本轮补齐 |
| 顶栏状态 | 运行状态文字变化 | 短 Crossfade | 本轮补齐 |

| 审批/工作流/专家团 | 等待、批准、拒绝、运行、完成、失败 | 保持现有业务状态与 Material 3 控件反馈；专属状态动效待页面逐项核对 | 待核对 |
| 目录/列表 | 展开、折叠、筛选 | 只在真实存在展开状态的组件上使用 AnimatedVisibility/animateContentSize | 待核对 |

## 无障碍与性能约束

- 语义、点击区域、启用/禁用状态不因动画而改变。
- 不通过透明度隐藏仍可访问的控件；出现/消失使用 AnimatedVisibility。
- 不增加无限循环动画；无任务时不持续刷新。
- 不在每帧触发网络、数据库、持久化或模型请求。
- 动效只依赖现有 Compose 状态；动画结束不承担业务提交职责。
- 列表必须保留稳定 item key；消息 ID 是列表动画身份，不使用位置索引。
- 语音按住/松开发送、停止请求、权限申请等交互时序保持原样，动效不得改变业务行为。

## 本轮落地范围

- NestroApp.kt：页面切换、侧栏进出、顶栏状态、思考提示、输入区高度、发送/停止图标过渡。
- NestroComponents.kt：消息列表 item 进入/移除/重排动画。
- VoiceInputButton.kt：保留现有录音缩放/颜色/触觉反馈，不重写语音控制器。
- 普通 Material 3 控件继续使用默认交互反馈，不全局覆盖系统 ripple。
- 统一验证阶段再做编译、Compose UI 测试与真机帧率/触控手感验收；源码修改不等于已通过验收。
