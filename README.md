# Nestro

**Nestro 是一个开源、本地优先的 Android AI 工作站。** 它希望把 AI 对话、项目知识、长期记忆、专家团队、Skills、MCP、Git 开发和手机自动化整合到一个自然语言入口中，让用户描述目标，由系统组织能力完成工作。

Nestro 不运营自营账号系统，也不托管用户的模型推理服务。用户自行选择兼容的模型服务商并配置 API Key。

> **当前阶段：核心底座与部分执行能力已落地，整体仍在开发中。** 本页区分“代码已有初版”和“尚未完成”，不把界面占位、设计规划或未验证代码算作完整功能。除特别说明外，代码已提交不代表已通过构建，更不代表已在真实设备验收。

## 产品原则

- **用户选择模型**：当前接入 OpenAI Chat Completions 兼容接口，模型请求由设备直接发送到用户配置的服务端。
- **本地优先**：会话、项目数据、知识库、记忆及配置保存在应用私有空间；API Key 使用 Android Keystore 加密。
- **一个自然语言入口**：目标是从同一个对话窗口调度专家、团队、Skills、工作流、MCP、Git 和 Phone Agent。
- **权限由用户掌握**：Android 无障碍、麦克风等敏感权限需用户授权；支付、转账、凭据输入等高风险动作必须交还用户确认。
- **安全可审查**：AI 生成的配置、技能和代码变更应经过来源检查、权限说明、预览与用户批准，不静默扩大权限。
- **轻量运行**：不依赖 Nestro 自建云端常驻推理服务；网络和文件工作放在后台线程，能力按需运行。

## 当前进度

### 已有代码初版

以下能力已经有对应代码，但仍可能需要构建修复、测试或真机验收：

#### 应用与数据底座
- Kotlin + Jetpack Compose Android 应用，深色界面与薄荷绿强调色。
- Room 本地数据库保存会话、消息、项目空间、知识库数据、Phone Agent 任务记录和项目级自动记忆。
- 支持数据库版本迁移；旧版本地会话数据有迁移兼容逻辑。
- 项目创建、重命名、切换；会话按项目隔离，项目指令仅注入当前项目上下文。
- 本地 JSON 备份/恢复初版，API Key 不进入备份。

#### 对话与记忆
- 多会话创建、切换、删除、搜索和重命名；每个会话独立保存输入草稿。
- SSE 流式回复、停止生成；请求绑定原会话 ID，避免切换会话后把迟到回复写错窗口。
- 请求历史与系统上下文有长度限制，避免无限增长。
- 手动全局记忆可跨会话使用。
- 当前项目内跨会话关键词召回初版，召回结果保留来源会话和消息标识。
- 项目级自动记忆支持用户主动开启/关闭；默认关闭。开启后仅对符合规则的消息额外请求模型提取候选，发送前做本地敏感内容规则预检，返回后再过滤、去重并本地保存；支持关键词召回、单条编辑和删除。规则预检不能保证识别所有敏感内容；尚未具备语义向量检索。

#### 知识库
- 支持 TXT、Markdown、HTML、CSV、JSON、XML 等文本文件的本地导入与解析。
- 已有文档分块、项目内关键词检索和 RAG 上下文注入初版。
- 删除文档时会清理关联知识片段。

#### 专家与 Skills
- 内置专家入口、自定义专家提示词。
- 内置技能与自定义技能创建、编辑和删除。
- 已有本地 JSON/Markdown 技能包解析，以及版本、依赖和权限声明的基础校验与安装前预览。
- 专家团队协作和外部技能仓库的完整生命周期尚未完成。

#### 语音
- Android 系统语音识别入口，支持按住录音、部分结果回填、松开发送、权限提示和错误反馈。
- 系统 TTS 支持中文朗读/停止、语速调节、中文音色选择、语言可用性检测与可选连续播放队列；真机体验仍待验证。

#### 后台任务、产物与能力目录
- Phone Agent 任务可通过系统通知查看运行、暂停、待接手和完成状态；通知栏可发起停止请求，任务页可人工核对后继续、重试或取消。
- WorkManager 长任务使用用户可见的前台通知运行；异常或中断后不自动重放可能已执行的 UI 动作，任务会停在待核验状态，由用户核对页面后手动继续或重试。
- 产物库支持按项目保存助手回复或手动创建 Markdown，提供版本递增、预览、分享、导出和删除。产物内容已纳入带 SHA-256 校验的 JSON 备份/恢复，并按项目归属校验。
- 能力目录动态展示内置能力与本地已安装技能的状态、包内来源声明、权限声明和依赖；包内来源属于文件自述，尚未进行签名验证。远程社区目录、签名校验和第三方安装尚未接入。

#### Phone Agent 手机操作
- 已注册 Android AccessibilityService，并提供用户手动前往系统设置授权的入口。
- 已有当前窗口可访问文本读取、密码字段跳过、基础可见文本点击。
- 已有模型驱动的多轮观察-规划-执行循环、严格 JSON 动作解析和类型化动作执行初版。
- 已有临时授权、撤销、本地动作审计、动作后页面状态检查。
- 已接入 WorkManager 持久化串行队列、进度持久化和中断后恢复入口；同一时间只调度一个手机操作任务，避免并发控制同一界面。操作状态不明确时保留待核验状态，不自动重放不确定动作。
- 已加入任务状态通知、Android 14+ 用户主动任务专用前台服务、通知栏停止请求；异常后保留待核验状态，不自动重放不确定动作。通知权限需用户授予，厂商后台限制仍待真机验收。
- 目前仍受 Android 无障碍可访问性、应用自绘控件、安全页面、登录验证和厂商后台策略限制，不能视为稳定的通用手机代办 Agent。

#### 工程
- GitHub Actions 已配置 Android debug APK 云端构建与 artifact 上传。
- 已有部分 Phone Agent 和技能解析单元测试。

## Phone Agent 的目标体验

用户只需描述目标，例如“帮我买一杯咖啡”。Agent 应自行理解规格、预算和配送要求，搜索可用平台，比较商品价格、配送费、优惠、预计送达、库存和商家可信度，再按最终到手价与用户偏好排序。

用户选定后，Agent 可在授权范围内打开 App 或网页，完成低风险步骤，并在每一步核验实际页面状态。提交订单、支付、转账等不可逆或高风险操作前，必须展示完整明细并取得用户明确确认。

登录、验证码、人机验证、风控或无法核实的页面应暂停并交由用户处理；不得输入支付密码、绕过安全验证或伪造价格、库存和优惠。订餐、订票、预约、商品比价和网页表单等任务最终复用同一套“目标理解 → 信息收集 → 决策 → 执行 → 核验 → 用户确认”引擎。

**上述内容是产品目标和验收边界，不代表完整购物闭环已经实现。**

## 模型配置

在应用的「模型管理」中填写：

- API Base URL，例如 `https://api.example.com/v1`
- 服务商提供的模型标识
- 用户自己的 API Key

应用请求 `POST {baseUrl}/chat/completions`。不同服务商的兼容程度可能不同，可先使用连接测试。API Key 使用当前设备 Android Keystore 加密，不写入仓库，也不包含在备份中。

## 本地数据与隐私说明

- 会话、项目数据和本地知识库保存在应用私有存储；API Key 使用 Android Keystore 加密。
- 备份文件由用户自行保存。恢复备份不会恢复 API Key。
- **自动记忆默认关闭。** 用户在「全局记忆」页面主动开启后，符合规则的消息才会触发额外的模型提取请求；发送前会在本机执行基础敏感内容规则预检，候选结果返回后再次过滤并保存在本机。规则预检并非完美识别器，不能保证拦截所有敏感内容。开启后，符合条件的消息会额外发送给用户配置的模型服务；关闭后不会发起这类额外提取请求。
- Android 语音识别由系统识别服务提供。是否联网以及音频是否交给系统服务处理，取决于设备上的识别提供方及其设置，不能笼统视为完全离线。
- Android 无障碍服务只有在用户手动授权后才能使用，且无法保证读取所有 App 的自绘控件或安全页面。

## 构建与验证

推送到 `main` 会触发 GitHub Actions，生成 `Nestro-debug-apk` artifact。可在仓库 Actions 页面查看构建记录并下载产物。

CI 成功只表示云端编译和打包通过，不代表实体设备验收完成。安装升级、数据库迁移、键盘避让、语音、无障碍操作、后台恢复、网络兼容、性能和耗电仍需在真实 Android 设备验证。
