# Nestro

Nestro 是一个开源、本地优先的 Android AI 工作站。它把对话、跨会话记忆、专家与技能、手机操作入口和后续扩展工具放在同一个工作界面中。Nestro 不运营自营账号系统，也不托管用户的模型推理服务。用户自行选择模型服务商并提供 API Key。

## 产品原则

- **模型由用户选择**：支持 OpenAI Chat Completions 兼容接口；模型请求直接从设备发送到用户配置的服务端。
- **本地优先**：会话、全局记忆、专家和技能配置保存在应用私有空间。API Key 使用 Android Keystore 的 AES-GCM 加密。
- **能力统一入口**：目标是通过同一对话入口调度专家、技能、项目、工作流、MCP 和 Phone Agent，而不是让用户记住一堆孤立页面。
- **权限由用户掌握**：Android 无障碍、麦克风等敏感权限必须由用户明确授权。支付、转账、凭据和敏感信息操作必须交还用户确认。
- **轻量运行**：不依赖 Nestro 自建云端常驻服务；模型请求放在 IO 线程，非必要能力不常驻运行。

## 当前已实现

### 本地数据层
- 会话、消息和项目空间使用 Room 数据库存储。
- 首次启动时从旧版 SharedPreferences/JSON 会话数据迁移；保留本地备份兼容镜像。
- 会话与消息更新通过数据库事务写入，API Key 仍独立保存在 Android Keystore。

### 项目空间
- 支持创建、编辑和切换项目空间，每个项目拥有独立会话列表。
- 支持项目级系统指令，仅在该项目会话请求中注入；不会自动混用其他项目的会话内容。
- 项目与会话关联数据进入本地 JSON 备份；空项目可删除，含对话的项目需先处理对话。

### 对话与记忆
- Kotlin + Jetpack Compose Android 应用，深色界面与薄荷绿强调色。
- OpenAI Chat Completions 兼容接口配置、连接测试和本地加密 Key 保存。
- 多会话创建、切换、删除和本地持久化。
- SSE 流式回复与停止生成。
- 每个会话独立保存输入草稿，切换窗口或应用重启后可恢复。
- 请求历史限制最近 40 条、48,000 字符，系统上下文限制 16,000 字符，避免无限膨胀。
- 会话标题及消息内容搜索、手动重命名。
- 旧版单列表聊天记录迁移到默认会话。
- 手动编辑的全局记忆跨会话注入模型系统上下文。
- 切换会话期间，已发起的模型请求按原会话 ID 保存回复，避免写入当前新会话。
- 本地 JSON 备份与恢复，包含当前支持的会话、项目空间、记忆、专家和技能数据；不导出 API Key。

### 专家与技能
- 内置专家入口和自定义专家提示词。
- 本地技能库，包含结构化总结、精简改写、代码审查等内置技能。
- 支持创建、编辑和删除自定义技能；所选专家提示词与技能提示词组合进入模型上下文。

### 语音与交互
- Android 系统语音识别入口，按住录音、松开发起识别并发送结果。
- 语音识别支持部分结果实时回填、识别状态提示和错误反馈。
- 麦克风权限由系统运行时授权。
- 录音状态具备缩放、颜色和触觉反馈；每次识别结束或出错后释放语音识别器。
- 输入法弹出时采用窗口 resize 与输入区 IME inset 避让，减少键盘遮挡输入框。
- 消息列表在新消息到达时平滑滚动。

### Phone Agent（早期执行器）
- 已声明 Android AccessibilityService，并提供用户前往系统设置手动授权的入口。
- 支持用户主动读取当前窗口可访问文本、基础可见文本点击、临时单次/任务授权、撤销授权和本地审计。
- 不自动扫描无障碍事件内容；密码字段不读取。
- 当前不是完整自然语言手机 Agent，尚缺任务规划、连续操作状态机、动作验证、异常恢复和完整风险复核。Android 无障碍能力也受应用自绘控件、安全页面和系统版本限制。

### 工程与交付
- GitHub Actions 自动执行 Android debug APK 构建并上传构建产物。
- CI 成功仅表示云端编译和打包成功，不代表已完成实体设备验收。

## 模型配置

在「模型管理」填写：

- API Base URL，例如 `https://api.example.com/v1`
- 服务商提供的模型标识
- 用户自己的 API Key

应用请求 `POST {baseUrl}/chat/completions`。服务商兼容程度不同，可先使用「测试连接」验证。Key 使用当前设备 Android Keystore 加密，不写入仓库、不包含在备份中。

## 本地数据与隐私

会话、全局记忆、专家提示词和技能配置保存在应用私有存储。备份文件由用户自行保存。恢复备份不会恢复 API Key；如果模型服务地址或模型标识改变，必须重新检查 Key 和目标服务商。

语音识别由 Android 系统识别服务提供。识别服务是否联网、音频是否交给系统服务处理，取决于设备上的语音识别提供方及其设置；不能将其笼统描述为完全离线。

## 性能原则

- 不在主线程执行模型网络请求、文件解析或索引构建。
- 不为未使用的 Phone Agent、MCP 或知识库能力启动常驻轮询。
- 限制发送给模型的历史消息数量，并逐步加入 Token 预算与上下文裁剪。
- Compose 列表使用惰性布局；避免每帧无意义状态更新和重复序列化。
- 后台任务按需运行，具备取消、超时、重试和状态持久化策略。
- 性能结论必须通过设备实测，不以代码推断替代耗电与流畅度测试。

## 构建与验证

推送到 `main` 会触发 GitHub Actions，生成 `Nestro-debug-apk` artifact。可在仓库 Actions 页面下载。CI 构建成功只代表云端编译和打包通过；安装、键盘避让、语音体验、后台行为、网络兼容、数据迁移和耗电情况仍需在实体 Android 设备验证。
