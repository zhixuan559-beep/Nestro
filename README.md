# Nestro

Open-source, local-first Android AI workspace. No Nestro account required.

## Status

Initial Android application scaffold. Model providers, local database, knowledge base, MCP, skills, Git integrations and AI-assisted project generation are not implemented yet.

## Build

GitHub Actions builds a debug APK on pushes and pull requests to `main` and uploads it as an artifact.

## Security

Do not commit API keys, access tokens, signing keys, private user data or local configuration. Provider credentials should be protected with Android Keystore-backed encryption. Keep release signing keys outside this repository.
